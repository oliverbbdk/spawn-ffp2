SPAWN / FFP2

Åbn index.html i en browser. Ingen installation eller internet kræves til selve websitet.
Eksterne kildelinks kræver internet. Alle fonte er lokale; licens i assets/OFL.txt.

Upload: Pak ZIP ud. Upload index.html, de øvrige HTML-filer, style.css, script.js og assets-mappen til webhotellets offentlige webrod. Bevar mappestrukturen. Test alle fem sider på den offentliggjorte URL.

GitHub: https://github.com/oliverbbdk/spawn-ffp2
Den oprindelige lokale Git-historik følger med som Git-historik.bundle. Import: git clone Git-historik.bundle spawn

Figma: https://www.figma.com/design/HAbmppxeuQTQxomouzxzL8
