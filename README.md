# SPAWN – gaming for begyndere

Fem statiske, responsive sider med HTML, CSS og JavaScript. Åbn `index.html` lokalt. Ingen installation er nødvendig.

## Original Git-historik

Den oprindelige udviklingshistorik er bevaret i [Git-historik.bundle](Git-historik.bundle). Den indeholder fire lokale commits fra 29. september 2026: HTML/assets, CSS/JavaScript, læsbar kode og en rettelse af reset-knappen uden JavaScript. De første to commits blev registreret samme sekund. `main` viser den senere publicering og dokumentation; den er ikke den oprindelige udviklingsgren.

Download bundle-filen og kør:

```sh
git clone Git-historik.bundle spawn-original
git -C spawn-original log --oneline
```

## Test

Alle fem sider er tidligere testet ved 320, 390, 768 og 1280 px i Edge. En ny funktionstest fra ZIP den 2. oktober 2026 bekræftede siderne, navigationen, alle fire guidevalg og tjeklistens optælling/nulstilling. Hosting på Simply.com er endnu ikke testet.

## Billeder og skrifttype

Hjemmesiden bruger ingen stockfotos eller eksterne billedtjenester. Gaming-illustrationen er lavet i CSS; favicon er projektets egen SVG. Inter følger lokalt med sin SIL Open Font License i `assets/OFL.txt`.
